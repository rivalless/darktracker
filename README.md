# Dark Tracker

Dark grenade tracker for Lost Ark raids, made by **rivalless** · Discord `.rivalless`.

**[Download for Windows](https://github.com/rivalless/darktracker/releases/latest/download/DarkTracker-windows.zip)**: unzip it anywhere and open `DarkTracker.exe`. Nothing else to install.

How it works and the live room for your raid: https://lostark-darks.vercel.app

This repository only holds the downloads.
